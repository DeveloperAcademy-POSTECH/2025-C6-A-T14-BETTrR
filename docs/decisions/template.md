# 결정 제목

- 날짜: YYYY-MM-DD
- 상태: 제안 / 채택 / 대체됨
- 관련 이슈·PR: 링크
- 대체 관계: 해당 시 이전·후속 ADR 링크

`채택`은 설계 원칙의 확정을 의미한다. 구현 완료 여부는 관련 이슈에서 추적한다.

## 배경

현재 코드의 문제, 확인한 근거, 외부 제약과 적용 범위를 적는다.

## 결정

선택한 책임 경계와 핵심 정책을 짧게 적는다. 기존 계약·명세는 링크하고,
세부 시나리오와 작업 체크리스트를 복제하지 않는다.

## 대안과 보류 이유

검토한 선택지와 채택하지 않은 이유를 적는다.

## 결과와 비용

얻는 이점, 추가되는 부담, 적용 범위의 한계를 적는다.

## 검증

결정을 확인할 방법이나 관련 테스트·이슈를 링크한다. 실행 결과는 PR에 남긴다.
다른 기록으로 충분하면 이 절은 생략한다.

## 재검토 조건

어떤 제품·기술·팀의 변화가 생기면 결정을 다시 판단할지 적는다.
